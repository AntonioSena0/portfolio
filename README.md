# Portfólio — Antonio Sena

Site pessoal de Antonio Sena, desenvolvedor back-end Java.

## Stack do site

- Vite
- JavaScript puro (módulos ES)
- GSAP + ScrollTrigger
- Lenis
- Canvas 2D para a animação de partículas

## Como rodar

```bash
npm install
npm run dev
```

Build de produção:

```bash
npm run build
npm run preview
```
